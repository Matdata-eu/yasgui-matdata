Privacy Statement

Data Collection

This website does not use tracking or analytics to monitor your browsing activity. However, if you use the URL shortener feature, the shortened links are generated and stored on infrastructure operated by Matdata, and the service can see the URLs that have been shortened.

Third-Party Services

This website relies on several third-party services, which may have their own data collection practices:

  • Content Delivery Networks (CDNs): The JavaScript libraries and stylesheets used by this application are hosted on external CDNs (jsdelivr.net, cdnjs.cloudflare.com). These CDNs may collect anonymous usage statistics. Please refer to their respective privacy policies for more information.
  • Cloudflare DNS: The domain DNS is managed by Cloudflare. Some DNS traffic statistics may be collected for operational purposes. To our knowledge, these statistics are anonymous and do not contain personally identifiable information.
  • GitHub Pages: This website is hosted on GitHub Pages. GitHub does not collect or store HTTP access logs for GitHub Pages sites.

Local Storage

All application settings, including your queries, tabs, workspaces, and preferences, are stored locally in your browser's local storage. This data never leaves your device and is not transmitted to any server operated by Matdata.

URL Shortener

The URL shortener is hosted on Matdata-operated infrastructure. This means the operator of the shortener can see the full list of shortened URLs that have been generated. These URLs do not contain credentials themselves, but they do include the original URL, which may contain a SPARQL query. That query can potentially include credentials or other sensitive information embedded in the query string.

SPARQL Queries

When you execute a SPARQL query, it is sent directly from your browser to the SPARQL endpoint you have selected. Matdata does not see or log any of this traffic. The SPARQL endpoint you query may have its own logging and privacy policies. Please consult the documentation of the specific SPARQL endpoint for more information.

Tracking & Analytics

No tracking or analytics software has been intentionally added to this website. We do not use cookies, web beacons, or any other tracking mechanisms to monitor your activity.

Questions

If you have any questions or concerns about this privacy statement, please open an issue on our GitHub repository or contact us at matdata.eu.
